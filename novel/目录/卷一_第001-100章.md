# 卷一 愚人 · 第 001-100 章（1983 霜降 - 1984 夏 · 槐树村）

- 第001章 雷雨夜——霜降暴雨，傻子王小满失足落井；濒死幻象：井底有只举着秤的手
- 第002章 第1天——高烧三日醒来；哭声在他耳朵里"有了音高"，世界不一样了
- 第003章 第7天——帮六婶一口清乱账，吓着自己了；他躺上柴堆"发呆"，把全村家长里短听成了账本
- 第004章 心里的秤——集市上当场拆穿肉摊鬼秤（每斤短八钱），秤痞刘秤杆记恨
- 第005章 祖宗规矩——奶奶怕祸事罚他跪；夜里听来爷爷"金算盘"与公平秤的传说；上了锁的旧木匣
- 第006章 银镯子——马三赌局被王家设局坑到要卖娘的银镯；他看穿灌铅骰子与出千手法，首胜
- 第007章 麦场——王大彪带人围殴"出风头的傻子"；雨后麦垛滑成陷阱，他只挨三棍；夜里开始记"人账"
- 第008章 河边——周杏花被家里许给粮站主任之子；他一句"哭解决不了秤上的事，但账可以慢慢算"露了怯
- 第009章 三十七块五——第一单生意：北山收核桃卖给县酱菜厂，雇老栓叔的驴车；钱缝进炕洞
- 第010章 退亲——周有田上门当众退亲；他反手立下三年之约的字据，全村哗然
- 第011章 引线——刘秤杆勾结王有福放风"傻子疯了"；六婶看他的眼神变了
- 第012章 借书——聪明是引擎，知识是燃料；他蹭小穗的课本、缠人借广播报，如饥似渴
- 第013章 柴堆上的大学——白天装傻，夜里在灶灰上划线记天数；第一本自制"日进一寸"账本
- 第014章 王家的旧账——王大彪顺鸡不认账；他不动声色，把王家欠全村的恶一笔笔记下
- 第015章 集市地图——他心算出全镇八个集市的差价表，决定做"跑合"的中间生意
- 第016章 老栓叔的驴——用报恩换运力；五保户老栓成了他第一个"编外员工"
- 第017章 核桃又熟了——第二单放大；六婶入伙管账，三人班底成型
- 第018章 断货——王有福勾结供销社主任卡他的货源，第一次尝到"权"的滋味
- 第019章 破局的信息差——他翻出各生产队仓库底货绕开封锁；主任第一次听说这傻子的名字
- 第020章 全校第一——替小穗"背题"惊动老师；他装作只会背不懂，全校都说傻子有个神脑子
- 第021章 第二境的影子——心算越来越快，身体却越来越沉；熬夜第一次流鼻血（代价线立起）
- 第022章 奶奶的咳嗽——风湿性心脏病确诊，县医院手术要一百八；他第一次觉得钱少
- 第023章 山货的学问——他把山货生意做成"预购制"，让利一成收买人心；口碑即渠道
- 第024章 王有福的眼红——收"地皮钱"不成，放话让他"做不下去"
- 第025章 柴垛失火——夜里柴垛被点；他早把牲口圈挪了位置，救下驴车；这笔账记下了
- 第026章 半头猪——药死他半圈猪；小穗哭，他蹲在猪圈边算了一夜账：证据在哪
- 第027章 证据链——毒药来源、脚印、粮站的药单，他串成一条线；缺一个人证
- 第028章 二流子的良心——马三赌桌上听到王家吹牛；良心与把柄，他选了前者和后者都要
- 第029章 杏花的口信——杏花冒险递话：王有福要在他运货路上"摔车"
- 第030章 摔车——他反用其计，让王家的人自己"摔"进了公社的眼睛里；第一次借力打力
- 第031章 一百八十块——手术费凑齐那晚，他把每一笔账念给奶奶听；奶奶只说了句"别学坏"
- 第032章 县医院——第一次进城深处；他站在县医院走廊，看见更大的一张账网
- 第033章 手术室外——手术室外他算了一夜全村未来三年的收成；人生第一次觉得聪明不够用
- 第034章 走廊里的哭声——手术成功；他在走廊里哭，第50章的回声先埋在这里
- 第035章 奶奶醒了——奶奶拉着他的手："满儿，你自打落井，眼神就不一样了。"他心口一紧
- 第036章 装傻的艺术——他升级人设：依然"憨"，但"病好开了点窍"；半真半假最好用
- 第037章 第100天——**第一境·过目不忘**；他把整本账册看一眼就再没忘过
- 第038章 过目不忘的用处——一天记完全公社粮价；他把本事换成第一笔大单
- 第039章 供销社的怒火——主任发觉被绕过，放话"查他投机倒把"；1983年这四个字很重
- 第040章 风声——公社要来人查；六婶怕，奶奶怕，他把账目理成滴水不漏的"社员互助"
- 第041章 查账的人——公社干事上门；他把互助账摊开，干事越看越心惊
- 第042章 滴水不漏——政策文件他背得出条款页码；干事空手而归
- 第043章 秦振邦——公社书记秦振邦注意到这个"傻子"：他见过聪明人，没见过这样的
- 第044章 一碗面——秦书记借调他算包产方案；一碗面，一场谈，贵人线开启
- 第045章 包产方案——他算出的分配方案让全公社增产一成；功劳记在秦书记名下，他继续藏
- 第046章 增产的夏天——夏收丰收，全村第一次把他当"自家人"看
- 第047章 杏花的婚事近了——粮站催婚；杏花在河边坐了一下午，他远远看着没过去
- 第048章 老井的召唤——爷爷遗物在井底的传闻坐实；他开始算怎么打捞
- 第049章 下井——农闲水浅，马三下井，木匣出水；锈锁，他没在众人面前开
- 第050章 公平秤——匣中老秤一杆、账本残页；秤杆刻四字：**心里有秤**（图腾登场）
- 第051章 饥荒账——1960年全村真账：谁家藏粮、谁贪了救济——王守财的名字赫然在列
- 第052章 不动——他把账收进炕洞；马三怒，他说"时机未到，账不会跑"
- 第053章 供销主任的反扑——抬价抢购他的核桃渠道，想生生挤死他
- 第054章 让利——他把差价全让给农户换死忠；亏一时，赢一路
- 第055章 农户的秤——三十户农户按了手印只认王小满；主任的银弹打不进人心
- 第056章 杏花出嫁——杏花出嫁那天，他在北山收货没回村；账本上第一次记下一笔"私账"
- 第057章 粮站的新妇——杏花婚后持家有方；她暗中留意粮站进出，成了他的一条信息线
- 第058章 王有福的杀招——勾结粮站克扣他家"统购粮"，断奶奶的口粮
- 第059章 粮单——杏花冒死抄出克扣粮单；证据链第一次完整
- 第060章 公社对质——他被王有福反咬"闹事"，公社对质；他把粮单、饥荒账一并摆上桌
- 第061章 满堂寂静——二十三年前的账当众摊开；王守财当场中风
- 第062章 借东风——秦书记顺势启动清查；他只递账，不出头
- 第063章 撤职——王有福被撤队长；全村大会那天，奶奶坐了头排
- 第064章 宅基地——被占五年的宅基地归还；老屋地界，他用爷爷账上的老契说话
- 第065章 恩怨未了——王大彪扬言"走着瞧"；主任在县里四处告状，中boss引线埋下
- 第066章 副业社——他牵头办编织养殖副业社，全村入股；最早的合作制雏形
- 第067章 股份的手印——按手印分股那夜，老槐树下像过年；马三管外，六婶管内
- 第068章 小穗升学——小穗考上县中；他当补课先生，讲一道题，全校老师来听课
- 第069章 二境·一心多用——**第200天质变**；左手算账右手盘秤还能听墙根
- 第070章 拖拉机——副业社添置第一台拖拉机；运输线从驴车升级
- 第071章 主任的绊子——县供销系统发文"整顿"他；权力第一次正面压来
- 第072章 贷款被断——信用社贷款被卡；他第一次见识"一句话"的分量
- 第073章 行长的好奇——县银行行长听过增产方案的故事；一场茶谈，贵人二号线开
- 第074章 押合同贷款——他用整年供销合同做押；行长批了，全县第一份
- 第075章 主任的反手——一封检举信进县里：设备来路、倒卖清单、政委审他
- 第076章 又见查账——这次来的是县里的组；他把三年账目装订成册，附政策索引
- 第077章 挑不出错——查账组临走那句"这账做得比县里清楚"；主任失分
- 第078章 王大彪拦车——运输路上被拦；他停车递烟谈价，把打手谈成了客户
- 第079章 大彪的松动——王家失势后大彪没了活路；一颗棋子开始挪
- 第080章 全村大会——饥荒账余波+新账并案发难，王家在槐树村彻底倒台（卷一最大高潮）
- 第081章 立碑与翻篇——他把老契与饥荒账封存；"账清了，恩怨翻篇，教训留下"
- 第082章 秋收——副业社第一个分红年；户均分红顶半年口粮，全村服了
- 第083章 主任的背水一战——勾结邻县抬高全盘收购价，赌他资金链断
- 第084章 期货的雏形——**第400天·第四境·推演预判**；他反手签"预购合同"锁定明年量价，主任高价囤的货砸手里
- 第085章 崩盘——邻县货卖不出，主任挪用公款事发，停职审查
- 第086章 上头有人——主任背后的县商业局戚德海浮出水面（卷二反派登场预告）
- 第087章 见报——省报角落一则《山村副业社记事》，没提名字；秦书记笑着剪报存档
- 第088章 名帖——邻县大商人递名帖求合作；他婉拒："我要办的事，不在买卖上"
- 第089章 奶奶的相册——奶奶翻出他七岁前的照片；"这孩子本来就是尖子，老天爷收走又还回来了"
- 第090章 木匣的另一层——公平秤盒底夹层藏着半页爷爷手稿："秤者，衡也；心不正，则衡失"
- 第091章 传家的秤——他把公平秤挂在堂屋正梁下；每晚记完账，对秤看一眼
- 第092章 高考的消息——恢复高考第七年；小穗的同学议论考大学，他心里那扇门开了一条缝
- 第093章 三年课程——他把初高中课本借了个遍；一晚一本，越看越饿
- 第094章 想上学——他向秦书记提出想以社会青年身份报考；书记沉默半晌："我给你作保"
- 第095章 全家的决定——奶奶、小穗、马三、六婶开会；奶奶说："去。别管村里人怎么说"
- 第096章 县中的门槛——县中校长听说"傻子"要插班，笑着摇头；秦书记亲笔信压上
- 第097章 插班试——试读一个月；他在县城租下第一间小屋，柴堆换成了书桌
- 第098章 出山前夜——副业社交给村民理事会；他把规矩写成一册《社章》，人人按印
- 第099章 老槐树下——临行前给奶奶磕头；奶奶把公平秤的小铜锤系上红绳挂他脖子
- 第100章 出山——行李卷上卡车；村口相送；回望老井与老槐树——卷一终
