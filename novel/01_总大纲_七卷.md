# 《每天聪明百分之一》总大纲（七卷·700 章）

> 每章一句话目录见 `目录/` 文件夹；正文见 `正文/` 文件夹。

## 卷一 愚人（第 001-100 章）1983 霜降 - 1984 夏·槐树村

**主线**：落井获救 → 发现变化并藏拙 → 鬼秤立威 → 赌局救马三 → 第一单生意 → 奶奶病与医药费 → 打捞爷爷遗物（公平秤+饥荒账）→ "投机倒把"风波自辩惊动公社书记 → 饥荒账掀翻村霸王家 → 副业社起 → 全县山货产销一体社。

**关键节点**：第 45 天退亲立约（第 10 章）；第 100 天"过目不忘"（约第 37 章）、第 400 天"推演预判"（约第 84 章）；第 80 章饥荒账发难——卷一最大高潮。

**卷末钩子**：报纸第一次出现"红星公社"的名字；邻县大商人的名帖递到村里，他站在老槐树下对奶奶说："我要出山了。"

## 卷二 出山（第 101-200 章）1984 秋 - 1985 秋·云岭县城 → 清华

**主线**：县城插班"乡下傻小子"月考第一 → 与沈知微双天才暗战结盟 → 省城以物易物大单 → 被举报、靠山秦书记上调 → 押上高考这个公开考场 → 政审危机反手布局（股份分给村民成"集体经济典型"）→ 数学满分、作文《愚公搬家》引全国争议 → **全省状元**震动 → 戚德海倒台启动 → 文理双魁同校之约 → 全村送行、埋"日进一寸"木牌。

**关键节点**：第五境·融会贯通（约第 135 章）、第六境·直觉如神（约第 141 章，考前）、第七境·圆满（约第 180 章，清华入学）——他带着刚圆满的脑子和一个 17 岁少年见过的世界走进考场。

**卷末钩子**：进京火车上，邻座白发老人盯了他一路："小伙子，计算机，学不学？"

## 卷三 燕园（第 201-300 章）1985 秋 - 1988 夏·清华·中关村

**主线**：入学藏拙 2.0（"偏科怪才"人设）→ 严镜湖教授收入实验室 → 中关村攒机潮里看见"汉字系统"商机 → 与沈知微重逢、组队（韩磊/楚天阔）→ 首单 2 万 → 与高干子弟顾青峰的项目之争 → 段氏汉卡入关倾销 → 工作室被盗、代码彩蛋反杀 → 段天雄亲自北上收买不成 → 雨夜定情 → **奶奶去世（第 300 章，全书泪点之最）**，坟前立誓：五年，让"中国心"跑在中国人的电脑里。

**关键节点**：圆满（第 700 天，约第 180 章）之后，再无"境"，只剩"用"。第 1000 天（约第 248 章）他在日记里写：圆满之后，每天那百分之一去了哪里？答：去了身体扛不住的地方。

**卷末钩子**：段氏联合美国巨头赛思宣布进军大陆。

## 卷四 南下（第 301-400 章）1988 秋 - 1993·深圳

**主线**：毕业即下海，四人班底南下注册**日新科技** → 深圳生存战与"日新 1 号"中文终端机 → 电子展孤注一掷（算准对方设备当众死机的时间）→ 段氏三板斧（挖角/诉讼/断供）逐一反杀 → 逆周期抄底、吸纳国企工程师 → 汉卡芯片化、产学研会师 → 预判南巡、股票认购证名场面 → 1992 全部身家押上扩产 → **不接价格战**，直营+行业定制，算准段氏资金链断裂的"天" → 段天雄香港败退，顾青峰出走美国投赛思。

**卷末题眼**：25 岁的他站在深圳国贸大厦顶层："他们说我一天聪明百分之一……其实我只是不肯停。"

## 卷五 风暴（第 401-500 章）1994-2007·全国·香港

**主线**：上市与对赌条款埋雷 → 回村办婚礼（王有福敬酒，恩怨半消）→ 砍掉地产守住主业、"日新芯二号"通用 CPU 流片 → 儿子念安出生、顾青峰以赛思全球副总裁身份对峙 → 从泰铢远期汇率的异常**提前推演金融风暴**，全公司备战过冬被骂"疯子" → 1997 风暴爆发、股价腰斩、段飞白联合对冲基金狙击 → 严镜湖病逝托孤 → 提前回笼的现金+员工持股+反向狙击（1998 香港保卫战民间版）→ 对赌解除、投行老将反被算服入董事会 → 与沈知微和解 → 1999 国庆观礼，日新登顶亚洲 → 2000-2007：愚公计划、反"免费战争"、入世出海、非典供应链保卫战、云的雏形、2008 前夜的第三次战备。

**卷末钩子**：赛思发布"全球操作系统 2.0"，顾青峰的宣战书只有一行字：让每台电脑都跑赛思的芯。

## 卷六 弈局（第 501-600 章）2008-2012·世界

**主线**：转型系统+芯片+云（赛马制）→ 瓦森纳封锁下绕道开源，**"愚公架构"**问世，被嘲讽"中国愚公"便引以为号 → 赛思专利战首胜（十年前埋的彩蛋逐一引爆）→ 神秘智库**墨塔**浮出水面：亚当·凯尔与药物天才陆沉 → 陆沉一夜攻破日新云、两人远程对弈平手 → 国际标准投票险胜 → 2008 金融海啸提前一年收缩、逆势收购欧洲芯片厂 → 墨塔联合华尔街恶意收购 → **股权保卫战**，陆沉反水倒戈（镜像主题爆发：速成的聪明是病）→ 墨塔溃败、凯尔被弹劾、陆沉狱中交出黑档案赎罪 → 顾青峰众叛亲离，主角却救了他病重的女儿。

**卷末**：2012 年日新成为全球市值第一的科技公司；45 岁的王小满在顶层失眠——"然后，呢？"

## 卷七 归处（第 601-700 章）2013-2024·巅峰·槐树村

**主线**：卸任 CEO 只留董事长、程一苇接棒 → 回村建日新乡村学校 → 押注"认知增强"：不做替代人的 AI，做放大人的"日进一寸"学习系统 → 陆沉减刑出狱、记忆衰退成"半个废人"，主角养他、研究他，让他余生参与算法（"你把你的好运，分给了所有人"）→ 墨塔残部最后的深度伪造危机，主角推动开放给全球的"日新协议" → 念安选择回乡当教师；知夏读脑科学 → **金手指之谜三种解释并列，主角亲口拆穿神话**（"每天百分之一，谁坚持四十年都一样"）→ 告老还乡，陪 90 岁的王有福晒太阳 → 写回忆录《傻子日记》，在奶奶坟前烧样书 → 终章：被欺负的留守少年小石头来问"我是不是一辈子就这样了"，他把当年老井边的答案原样递出去；2024 霜降雷雨夜，老槐树下坐到天亮——"第 14976 天，开始。"

## 续写规则（给后续批量生产的自己）
1. 每章 1800-2400 字，卷一每章开头带「第 N 天」日记扉页（卷二起改为间歇出现，重大"天"数必须点出）。
2. 每 10 章一个小高潮；每章结尾留钩子。
3. 爽点必须"当众验证"——聪明的爽，要落在具体的人、具体的账、具体的秤上。
4. 伏笔登记制：新埋伏笔记入本章，回收时引用原章号。
5. 时代事件只用不背书：作为背景板出现，不替历史人物编台词。
