# 《同一阵风》THE SAME WIND — 项目开发包

国际公路 / 诗意现实主义长片。**第一轮交付：第一场（华北平原 · 麦收夜）**，14 镜 / 98 秒，可渲染。

---

## 一句话

**一个女人追着距离走了一辈子，最后发现家也是会动的。**

## 国际场面的核心设计

**同一阵风，穿过五国。**

风从华北平原起，向西越过哈萨克草原、里海、高加索、东欧平原，最后回到起点。
每一站都有一个人在做**完全相同的动作**：站在风里，举着一部屏幕空白的手机。

```
北纬 35.5°  华北平原   —— 十一台联合收割机像一支舰队横过夜里的麦田
北纬 43.2°  哈萨克斯坦 —— 白色风车森林，像有人把骨头插在地上
北纬 41.7°  格鲁吉亚   —— 第比利斯旧货市场，摊主在风里压住一块塑料布
北纬 52.2°  波兰       —— 雪地里的白色风车，芦苇全部倒向一侧
东经 170°   太平洋     —— 甲板上集装箱像一座飘在海上的城
北纬 35.5°  回到起点   —— 收割过的麦田，拂晓
```

字幕卡只有经纬度和海拔，**没有国名、没有地名**。任何语言的观众都能在第一分钟进入。

**结尾全片只有五个字**：她终于收到消息，不是她等了一辈子的那个。屏幕上：**「麦子收了。」**
她删掉打了很久的草稿，回了一个字：**「嗯。」**

## 第一场是怎么排的（14 镜 / 98 秒）

### 全片技术纪律（不是逐镜随机，是代码级统一）

- **只用两支镜头**：**40mm** = 风景与人（让地平线进入画面）；**100mm** = 远处的机械与手。
  **全片不用中景 50mm**——中景会让人变成"对话中的人"，而本片没有人对话。
- **天空占画面三分之二**，地平线压在下三分之一。这是本片最重要的构图纪律。
- **90% 固定机位**。唯一的运动是**风造成的画面内运动**。第一场只有两次移动摄影机：
  sw007 跟收割机横移一次，sw014 结尾缓拉一次。
- **只允许四种光源**：天空 / 机械灯 / 火 / 屏幕。**没有一盏灯是为了照亮演员而存在的。**
- **铝壶底部的黑圈**、**褪色的红布条**是全片道具锚点，跨镜必须一致。

### 第一场的三个"被照亮又暗下去"

| 镜头 | 内容 | 为什么重要 |
|---|---|---|
| sw004 | 十一台收割机像舰队从地平线升起 | 全片最重要的场面镜 |
| sw005 | 第一台的两盏探照灯把她照得发白，两秒后转走 | **本片的题眼**：她被照亮两秒，然后被还回黑暗 |
| sw007 | 十一台依次经过，每一台短暂地把她照亮一次 | 一镜到底，不许剪成十一次 |

### 埋下的伏笔

- **院门没有锁，只是带上**——她以为自己会回来。第 6 场回收：院门已经是别人的了。
- **红布条**（儿子出生那年绑的）——第一次出现在 sw011，最后一次出现在结尾田埂上。

### 出片路径

```bash
# 0) 先设 Key（智谱），否则流水线进入 mock 演示模式
export AI_API_KEY=<你的智谱 Key>

# 1) 试渲 3 个纯风景镜头——约 4.8 元
#    sw001 麦田大远景 / sw004 收割机车队 / sw006 拨禾轮扬麦芒
#    ★ 这 3 镜里没有人，不需要参考帧，不需要定妆，直接看风的效果
./bin/studio render --run runs/run-20260926-090500-samewind --shots sw001,sw004,sw006

# 2) 看画质。满意就全量（约 22.4 元）
./bin/studio render --run runs/run-20260926-090500-samewind

# 3) 交付：配音 + 字幕 + 混音 + 合成 + 成片校验
./bin/studio deliver --run runs/run-20260926-090500-samewind

# 4) 复核
./bin/studio verify --run runs/run-20260926-090500-samewind
```

> **成本**：第一场 14 镜全量 ≈ **22.4 元**。全片 6 个地理单元约 96 镜 ≈ **150 元**。

## 为什么这个故事适合这条流水线

| 本片需求 | 生成工具表现 | 结论 |
|---|---|---|
| 大风景 + 风 | 极强（模型看过最多的就是风光） | ✅ 主力 |
| 单人剪影 / 背影 / 侧脸 | 极强（不需要口型同步） | ✅ 主力 |
| 机械运动（收割机、风车、船） | 强（物理感好，不需精确手指） | ✅ 主力 |
| 火、蒸汽、雪、水、尘 | 强 | ✅ 主力 |
| 手机屏幕 | 强（UI 后期叠加，不靠生成） | ✅ 后期 |
| 多人对话正反打 | **弱** | ❌ 全片规避 |
| 精细手指动作 | **弱** | ⚠️ 全片仅一处 |
| 精确口型同步 | **弱** | ❌ 全片 11 句台词，全部背对或无嘴部特写 |
| 人群正脸 | **弱** | ❌ 人群只用剪影与车灯 |

**约 92% 的镜头落在模型能力区的中心。**这是它比一般故事更适合这条流水线的原因。
**约束反而逼出了更好的电影**：在 AI 生成条件下，沉默是最好拍的东西，也是最国际的语言。
